# Contributing

Thanks for helping improve RealmsNetwork AIBot.

## Before opening a pull request

1. Open an issue for significant features or behavior changes.
2. Keep changes focused and avoid committing secrets, tokens, logs, or local configuration.
3. Run `npm run check` and `npm test`.
4. Update the README or configuration documentation when behavior changes.
5. Never include user tokens, API keys, private messages, or production server data in tests or logs.

## Pull requests

Explain the problem, the solution, configuration changes, and how you tested it. New features should include tests where practical.

## Security issues

Do not publish working exploits or secrets in public issues. Follow the reporting instructions in SECURITY.md.
